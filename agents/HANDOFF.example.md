# Local maintenance handoff

Copy to `agents/HANDOFF.md` for an operated instance. Keep this file local.
Replace the current summary at each session boundary; archive detailed evidence in
`agents/reviews/` or the ignored maintenance reports directory.

- Updated at (absolute timestamp and timezone):
- User objective, constraints, budget and permissions:
- Evidence window and actual live runs; synthetic events excluded:
- Source commit and runtime build; how loading was verified:
- Current mission, blockers, outstanding deliveries and pilot expiry:
- Changes implemented / tested / loaded / verified:
- State edits and backup paths, or none:
- Next verification and success/failure evidence:
- Services left running and log locations:

Never record credentials. Source changes do not prove deployment or gameplay success.
