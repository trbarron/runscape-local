# Ferry fishing

The resource index includes the Musa Point cage/harpoon cluster marked for ferry
travel. Species targets enforce tuna Fishing 35, lobster 40 and swordfish 50.
Mission feasibility reserves 60 own coins for the round trip plus required tools.

Execution pays the 30-coin Port Sarim fare in each direction, handles the ship hold
and ladder, crosses the gangplank and returns to the mainland after gathering.
Karamjan rum blocks the route rather than allowing customs to confiscate it.
Indexed ferry spots are not ordinary mainland walking destinations.

Source fixtures cover ferry navigation and fishing requirements. A live route check
must separately verify boarding, charges, actual catches and return from the indexed
cluster. Preserve accounts, saves and unrelated inventory during any such check.
